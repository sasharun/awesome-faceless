# Contribution Guidelines / 贡献指南

Thank you for helping keep **Awesome Faceless Content Creation** accurate, useful, and spam-free!

## How to Submit a Tool

1. **Pull Request (fastest):** Fork the repo, add one row to the right section in `README.md` (and optionally the localized READMEs: `README.zh-CN.md`, `README.es.md`, `README.ja.md`, `README.ko.md`), and open a PR.
2. **Issue form (no Git needed):** Open a [Tool Submission Issue](https://github.com/sasharun/awesome-faceless/issues/new?template=submit-tool.yml).

### Table Format

For tool sections:
```markdown
| [Tool Name](https://example.com/) | Concise job-to-be-done (under 80 chars) | Free / Freemium / From $X/mo | — |
```

For `Open-Source Pipelines & Agent Skills`:
```markdown
| [owner/repo](https://github.com/owner/repo) | What the pipeline does | Stars / License / Stack |
```

## Inclusion Criteria

We are intentionally selective so this list stays curated rather than becoming a link dump:

- **Direct relevance**: Must clearly serve a faceless YouTube / Shorts / TikTok creation workflow (research, scripting, TTS, video generation, editing/captions, thumbnails, automation, or analytics).
- **Accessible to try**: Open-source, free, or **Freemium with a meaningful free tier** (paid-only tools are accepted only if they are widely established industry standards).
- **Clean official URLs**: Direct canonical homepage or GitHub URL only — **no `?utm_source=...`, referral, or affiliate links**.
- **Active & live**: Working website or actively maintained GitHub repo (no dead links, parked domains, or abandoned wrappers).
- **No bot/bulk directory spam**: Automated multi-repo directory-bot PRs are closed automatically.
- **No copyright-infringing rippers**: We do not list watermark-removal / video-ripping bots.
- **No paid courses, coaching, or prompt-pack shops**.

## Localization

Translation improvements and regional tool recommendations are always welcome!
